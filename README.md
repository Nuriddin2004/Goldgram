# Goldgram for Android

Telegram / exteraGram / AyuGram ochiq manba kodiga asoslangan norasmiy Android klient.

## Yuklab olish

[Eng yangi Goldgram APK](https://github.com/Nuriddin2004/Goldgram/releases/latest/download/Goldgram.apk)

[Barcha versiyalar va yangiliklar](https://github.com/Nuriddin2004/Goldgram/releases)

Android 8+ va ARM64 telefonlar uchun. Avvalgi `uz.nurid.goldgram` ilovasi ustiga
o‘rnatiladi. APK'ni yangilash uchun eski ilovani o‘chirish kerak emas.

## Yangilanishlar

`9.6.6-Goldgram.2` dan boshlab, ilova ochilganda ko‘pi bilan har 6 soatda yangi
versiya tekshiriladi. Qo‘lda tekshirish uchun Preferences → Goldgram yangilanishlari
bo‘limini oching. Tekshirishni shu oynada o‘chirish mumkin.

APK yuklash tugma orqali boshlanadi. O‘rnatishni Android oynasida tasdiqlaysiz.
Fayl hajmi, SHA-256, paket nomi, versiya va imzo tekshiriladi.

## Manba kodi va litsenziya

Har bir release'dagi `Goldgram-source-<versionCode>.zip` shu APK'ga mos manba kodini,
o‘zgarishlarni, build yo‘riqnomasini, testlarni va upstream litsenziyalarini saqlaydi.
Yig‘ish tartibi arxivdagi `GOLDGRAM-BUILD.txt` faylida.

Asos: [AyuGram4A](https://github.com/AyuGram/AyuGram4A), `rewrite`, commit `70131456`,
Telegram 9.6.6 / exteraGram. Asosiy loyiha GPL-2.0; uchinchi tomon kutubxonalarining
alohida litsenziyalari manba arxivida saqlangan. Mualliflik qaydlari saqlanadi.

Bu rasmiy Telegram yoki AyuGram relizi emas. Telegram Premium server imkoniyatlari
mahalliy sozlamalar bilan ochilmaydi. Goldgram.3 dan boshlab API ID/hash talab qilinmaydi; telefon raqamingiz bilan kirasiz.

APK kompilatsiyasi va host testlari tekshirilgan. Haqiqiy Android telefonda
kirish, yangilanish, qo‘ng‘iroqlar va barcha upstream funksiyalar hali sinalmagan.
